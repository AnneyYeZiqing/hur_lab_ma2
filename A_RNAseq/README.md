### Codes and Scripts related to MA2 RNA-seq Analysis

Subfolders:
1. **A1_cmd_bash/** (documents command-line tools and bash scripts used during RNA-seq initial data processing and alignment (fastqc, adapter trimming (Trimmomatic), STAR alignment (STAR), featureCounts (subread))
2. **A2_R/** (contains R scripts used in the RNA-seq analysis (differential gene expression (DESeq2), Principal Component Analysis))
3. **A3_python/** (contains python scripts/Jupyter notebooks used in the RNA-seq analysis (plotting of heatmaps and volcano plots))
